# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users
Students and musicians looking up lyrics, notation, and audio for Indian Classical bandishes.

## Product Purpose
A fast, searchable database and community-driven platform where users can look up, contribute, and edit Indian Classical bandishes. It provides an audio-first experience that seamlessly pairs lyrics and notation with audio recordings.

## Positioning
A comprehensive, community-powered repository for Indian Classical Music that unifies fast search, user contributions, and an audio-first learning experience.

## Operating Context
Practicing musicians and students use the platform to quickly reference lyrics and notation, listen to reference recordings, or contribute new bandishes to the community repository.

## Capabilities and Constraints
- Fast search functionality (powered by Fuse.js).
- Data and auth backend (powered by Supabase).
- Modern web stack (Next.js, Tailwind CSS, Framer Motion).
- The visual design language and branding are open and will be established as we go.

## Evidence on Hand
The project is a fully built out Next.js application with 171 pages, including routes for bandishes, raags, editors, and authentication. It uses Supabase, Fuse.js, and Framer Motion.

## Product Principles
1. **Frictionless Discovery**: Finding a bandish must be instant and highly relevant.
2. **Integrated Experience**: Audio recordings and text notation/lyrics should feel like a single unified entity.
3. **Community-Driven**: Contributing and editing compositions must be intuitive to encourage community growth.
